Chapter 0 In-Class: Git Decisions

You already used Git in Xcode. This is not more clicking. It is “what would you do next, and why?”

Setup

Work in groups of three for about 15 minutes. Pick one recorder. That person writes the group’s answers.

Keep your GitPractice project nearby if you want. Do not open Terminal. Do not start a new project.

Key Ideas

Your Mac is the Notes app on your phone. GitHub is iCloud. Those two copies can be different.

A commit is hitting Save and adding a short note. A push is Upload to iCloud. A pull is Download from iCloud.

main is the version you would show a boss. A branch is a draft in a separate chat. A merge copies the good draft back.

How to Play

  1. Read each card out loud.
  2. Agree on one next move and one sentence why.
  3. Write what goes wrong if you pick the wrong move.
  4. Finish all six cards in about six minutes. Then we compare answers.

Pick one next move per card:

  • Commit
  • Push
  • Pull
  • Make a new branch
  • Merge into main, then push
  • Stop and commit (or throw away) leftover changes first

The Cards

Card A — Saved on the laptop, missing online

You put your name on the welcome screen. Xcode shows the file as changed. You open GitHub.com. The old text is still there.

What do you do next? What goes wrong if you skip a step?

Card B — You edited it on the website

You added a line to README.md on GitHub.com. Xcode still shows the old README.

What do you do next? What goes wrong if you push instead?

Card C — You want to try a risky idea

The app on main works. You want to add a tagline. You are not sure it will look good.

What do you do next? What goes wrong if you edit main directly?

Card D — The draft looks good

You are on the add-tagline branch. The tagline looks good. main still does not have it.

What do you do next? What goes wrong if you only merge and never push?

Card E — Push failed

Xcode says push was rejected. You (or a classmate) already changed the README on GitHub.com.

What do you do next? What goes wrong if you keep hitting Push?

Card F — Merge is stuck

You want to merge. Xcode will not merge. The Source Control list still shows files you have not committed.

What do you do next? What goes wrong if you ignore those leftover edits?

Exit Tickets

As a group, finish these two sentences. Write them on the recorder’s notes.

A commit is on my Mac. A push is ________________________________.

I use a branch so that if my idea is bad, ________________________________.
