Architecture Lab 3: The Memory

This is step 3 of 7. Plan on about 40 minutes with your team.

Introduction

You already showed one decision. This lab is about the Memory.

The Memory is what your app keeps. You will draw three drawers in the same Figma file.

Work with your team for about 40 minutes. Then each person turns in their own zip.

Use the same Figma link as the earlier labs. Your reflection must be your own words.

Learning Objectives

After this lab, you will be able to:

  • Name three things your app must still have tomorrow
  • Name one thing the app should forget
  • Mark which saved thing is private
  • Put one real example from your app in each drawer

Key Ideas

The Memory is the filing cabinet. It is still there after the shop closes. If you do not save it, it is gone when the app closes.

Not everything belongs in the cabinet. Some facts must last until tomorrow. Some should be thrown away.

Prerequisites

Finish Figma Basics. Your team needs a project you can describe in one sentence.

You need a free Figma account. Create one at figma.com/signup if you do not have one yet.

Lab Instructions

Part 1: Talk through the questions

Read these out loud. Answer them for your app, not for a sample app. Give this about 8 minutes.

  1. What must still be there tomorrow?
  2. What should be thrown away when the person closes the app?
  3. Which of those things is private?
  4. If you could keep only three things, what are they?

Part 2: Build the frame

Give this about 25 minutes. A classmate should understand the frame in 60 seconds.

  1. Open the same team file. Do not start a new file.
  2. Add a frame to the right. Name it 3 The Memory.
  3. Draw three rectangles. Treat them as drawers.
  4. Label each drawer. Put one real example from your app inside it.
  5. Mark the private drawer so a classmate can see it.
  6. Add one more shape. Label it Do not save. Write one example in it.

Your frame is done when it has all of these:

  • Three labeled drawers
  • One real example from your app in each drawer
  • A mark on anything private
  • A bin labeled Do not save

Part 3: Share and export

  1. Click Share in the top right.
  2. Set access to Anyone with the link can view.
  3. Copy the link. You will paste it in links.txt.
  4. Select the frame named 3 The Memory.
  5. In the properties panel, scroll to Export. Click +. Choose PNG at 1x.
  6. Export the frame. Save it as architecture-3-memory.png.

Put that PNG in a folder named screenshots. The file name must match exactly.

Reflection Questions

Answer in your own words. Write at least two sentences for each question. Do not copy a teammate.

  1. What three things does your app keep?
  2. What does your app throw away, and why?
  3. Which saved thing is private, and who should not see it?

Deliverables

Submit one zip file named architecture3-memory-lastname-firstname.zip. The team may share one Figma link. Each student still writes their own reflection.

  • links.txt with one line: Figma: and your view link
  • reflections.txt with Q1:, Q2:, and Q3:
  • screenshots/architecture-3-memory.png

Troubleshooting

Share link asks people to log in

Click Share. Set access to Anyone with the link can view. Copy that link into links.txt.

The export is blank or cropped

Select the outer frame named 3 The Memory. Do not select a text box inside it.

Every drawer says “user data”

Use a real example. A name, a score, or a saved place is clearer than a category.

You saved the password in a drawer

A password is a key, not a file. Note that it is private, and do not write a real password on the frame.

How to Submit on Canvas

Package your work as one zip file. Use the exact names in the Architecture Lab 3 submission guide.

Create your zip on a Mac

  1. Create a folder named architecture3-memory-lastname-firstname.
  2. Put links.txt, reflections.txt, and the screenshots folder inside it.
  3. Right-click the folder and choose Compress.
  4. Rename the zip if needed, then upload it to this Canvas assignment.

Compress the folder, not the loose files. See the Mac zip steps if you get stuck.
