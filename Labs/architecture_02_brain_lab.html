Architecture Lab 2: The Brain

This is step 2 of 7. Plan on about 40 minutes with your team.

Introduction

You already drew the Face. This lab is about the Brain.

The Brain is the rules and the decisions. You will draw one decision path in the same Figma file.

Work with your team for about 40 minutes. Then each person turns in their own zip.

Use the same Figma link as Lab 1. Your reflection must be your own words.

Learning Objectives

After this lab, you will be able to:

  • Pick one decision your app should make
  • Name the information that decision needs
  • Show what happens when the answer is no
  • Name one rule that must never be broken

Key Ideas

The Brain is the manager in the back room. The manager follows the rules and makes the decisions. The user should not have to do the math.

A screen can look fine and still make a bad decision. This frame shows one decision your app must get right.

Prerequisites

Finish Figma Basics. Your team needs a project you can describe in one sentence.

You need a free Figma account. Create one at figma.com/signup if you do not have one yet.

Lab Instructions

Part 1: Talk through the questions

Read these out loud. Answer them for your app, not for a sample app. Give this about 8 minutes.

  1. What is one decision the app should make so the user does not do the math?
  2. What information does that decision need?
  3. What happens when the answer is no?
  4. What rule must never be broken, even if someone asks?

Part 2: Build the frame

Give this about 25 minutes. A classmate should understand the frame in 60 seconds.

  1. Open the same team file from Architecture Lab 1. Do not start a new file.
  2. Press F. Draw a wide frame to the right of the Face. Name it 2 The Brain.
  3. Add four to six boxes for one decision in your app.
  4. Label the first box Start. Label one box with the check your app makes.
  5. Split the path. One side is yes. One side is no.
  6. Write what the user sees on each side. Use plain words. Do not write code.

Your frame is done when it has all of these:

  • Four to six boxes in one path
  • A start box
  • A check box
  • A yes path and a no path
  • Plain words from your app, not code

Part 3: Share and export

  1. Click Share in the top right.
  2. Set access to Anyone with the link can view.
  3. Copy the link. You will paste it in links.txt.
  4. Select the frame named 2 The Brain.
  5. In the properties panel, scroll to Export. Click +. Choose PNG at 1x.
  6. Export the frame. Save it as architecture-2-brain.png.

Put that PNG in a folder named screenshots. The file name must match exactly.

Reflection Questions

Answer in your own words. Write at least two sentences for each question. Do not copy a teammate.

  1. What decision does your app make, and what information does it need?
  2. What happens on the no path?
  3. What rule must never be broken?

Deliverables

Submit one zip file named architecture2-brain-lastname-firstname.zip. The team may share one Figma link. Each student still writes their own reflection.

  • links.txt with one line: Figma: and your view link
  • reflections.txt with Q1:, Q2:, and Q3:
  • screenshots/architecture-2-brain.png

Troubleshooting

Share link asks people to log in

Click Share. Set access to Anyone with the link can view. Copy that link into links.txt.

The export is blank or cropped

Select the outer frame named 2 The Brain. Do not select a text box inside it.

The path is really the whole app

Keep one decision. A path with twelve boxes is a wish list, not a brain.

You wrote code in the boxes

Use words a teammate can read out loud. Save the code for a later class.

How to Submit on Canvas

Package your work as one zip file. Use the exact names in the Architecture Lab 2 submission guide.

Create your zip on a Mac

  1. Create a folder named architecture2-brain-lastname-firstname.
  2. Put links.txt, reflections.txt, and the screenshots folder inside it.
  3. Right-click the folder and choose Compress.
  4. Rename the zip if needed, then upload it to this Canvas assignment.

Compress the folder, not the loose files. See the Mac zip steps if you get stuck.
