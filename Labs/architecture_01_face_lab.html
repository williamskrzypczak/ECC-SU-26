Architecture Lab 1: The Face

This is step 1 of 7. Plan on about 40 minutes with your team.

Introduction

Your team already has an app idea. This lab is about the Face.

The Face is what people see and touch. You will draw the first screen in Figma. You will not write code.

Work with your team for about 40 minutes. Then each person turns in their own zip.

The team may share one Figma file. Your reflection must be your own words.

Learning Objectives

After this lab, you will be able to:

  • Name the one job of your app’s first screen
  • Name three things a user can touch on that screen
  • Say what you left off the first screen on purpose
  • Build one Figma frame a classmate can read in 60 seconds

Key Ideas

The Face is the storefront window. People only know what they can see and touch. The first screen has one job.

A busy person gives your app about 10 seconds. If the first screen tries to do everything, they leave.

Prerequisites

Finish Figma Basics. Your team needs a project you can describe in one sentence.

You need a free Figma account. Create one at figma.com/signup if you do not have one yet.

Lab Instructions

Part 1: Talk through the questions

Read these out loud. Answer them for your app, not for a sample app. Give this about 8 minutes.

  1. If someone has 10 seconds, what is the one job of the first screen?
  2. What do they tap, type, or swipe? Name three touches.
  3. What belongs on a later screen?
  4. What would confuse a person who has never heard of this app?

Part 2: Build the frame

Give this about 25 minutes. A classmate should understand the frame in 60 seconds.

  1. Sign in at figma.com. Click New design file.
  2. Name the file with your app name plus the word Architecture.
  3. Press F. Choose an iPhone frame. Name it 1 The Face.
  4. Put your app name at the top of the phone.
  5. Add the one main action a new user should take.
  6. Label every button, field, and picture in plain words.
  7. Outside the phone, add a sticky note. Write what you left off on purpose.

Your frame is done when it has all of these:

  • One phone frame
  • Your app name
  • One main action
  • A label on every control
  • A note that says what you left off on purpose

Part 3: Share and export

  1. Click Share in the top right.
  2. Set access to Anyone with the link can view.
  3. Copy the link. You will paste it in links.txt.
  4. Select the frame named 1 The Face.
  5. In the properties panel, scroll to Export. Click +. Choose PNG at 1x.
  6. Export the frame. Save it as architecture-1-face.png.

Put that PNG in a folder named screenshots. The file name must match exactly.

Reflection Questions

Answer in your own words. Write at least two sentences for each question. Do not copy a teammate.

  1. What is the first thing a user should understand on this screen?
  2. What did you leave off the first screen, and why?
  3. How is this screen about your project, not a generic app?

Deliverables

Submit one zip file named architecture1-face-lastname-firstname.zip. The team may share one Figma link. Each student still writes their own reflection.

  • links.txt with one line: Figma: and your view link
  • reflections.txt with Q1:, Q2:, and Q3:
  • screenshots/architecture-1-face.png

Grading Rubric

Lab grading criteria (100 points total)
Criterion Points
The frame is about your own project 40
The frame includes the done-when pieces for The Face 25
Three reflections in your own words 20
View link and the named screenshot 15

Troubleshooting

Share link asks people to log in

Click Share. Set access to Anyone with the link can view. Copy that link into links.txt.

The export is blank or cropped

Select the outer frame named 1 The Face. Do not select a text box inside it.

The first screen is crowded

Keep one main action. Move the rest to the sticky note. A later lab can hold those ideas.

You started a second Figma file

Use one team file for all seven labs. Move this frame into that file before you share the link.

How to Submit on Canvas

Package your work as one zip file. Use the exact names in the Architecture Lab 1 submission guide.

Create your zip on a Mac

  1. Create a folder named architecture1-face-lastname-firstname.
  2. Put links.txt, reflections.txt, and the screenshots folder inside it.
  3. Right-click the folder and choose Compress.
  4. Rename the zip if needed, then upload it to this Canvas assignment.

Compress the folder, not the loose files. See the Mac zip steps if you get stuck.
