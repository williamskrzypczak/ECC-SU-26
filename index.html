Cursor AI

Cursor is the editor you use when you build the app with AI.

What Cursor is

  • Cursor is an AI code editor built on VS Code.
  • Your extensions, keys, and themes can move over in minutes.
  • It reads the whole project, not only the file you have open.
  • It can edit many files, run the terminal, run tests, and fix its own errors.

You set the goal and check the result. The AI does the building.

Getting started

  • Download Cursor from cursor.com (opens in a new tab). It runs on Mac, Windows, and Linux.
  • Hobby is free and is enough to learn. Pro is $20 a month and unlocks the full agent.
  • Open Cursor Settings, then Code Intelligence. Turn on Index Repositories for Instant Grep.

That setting lets Cursor search the whole project. It is not limited to the tabs you have open.

Ask, Plan, and Agent

Use them in this order: Ask, then Plan, then Agent.

  • Ask reads the code and explains it. It does not change files. Use it to learn a function, a new project, or a stack trace.
  • Plan agrees on the steps before any files change. Use it for a feature that would touch many files.
  • Agent does the work. It reads files, writes code, runs commands, and keeps going until the job is done.

Daily tools

  • Tab suggests the next lines. Press Tab to accept them.
  • Highlight code and press Command+K on a Mac, or Control+K on Windows, to edit it in plain language.
  • Read the side-by-side diff before you keep a change.
  • Press Command+I on a Mac, or Control+I on Windows, to open Composer and change many files at once.

Which tool to use

  • Tab is for speed inside one file.
  • Command+K is for one small, exact edit.
  • Composer and Agent are for work across many files.
  • Ask is for reading code and finding bugs.
  • Project rules keep the same style across the whole project.
