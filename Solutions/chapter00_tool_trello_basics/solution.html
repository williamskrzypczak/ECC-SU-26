Chapter 0 Solution: Trello Basics

Board name: Campus Welcome App Sprint

This reference shows the expected Trello board for the Chapter 0 lab. There is no code to copy. Your finished board is the solution.

Board Checklist

Your completed board should include:

  • Board: Campus Welcome App Sprint
  • Lists: To Do, In Progress, and Done
  • Cards: Set up Xcode project, Build ContentView welcome screen, Test in preview and simulator, Push project to GitHub
  • One card with a one-sentence description
  • Labels: Setup, Coding, and High priority, shown on the front of cards
  • Due dates on at least two cards
  • A checklist named Steps on the ContentView card, with at least one item checked
  • Cards in more than one list
  • A comment on a card in Done
  • A share link with view or edit access turned on
