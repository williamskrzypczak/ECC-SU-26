MAD 157 Canvas Lab Submission Instructions

Copy the assignment text for each lab into Canvas. Every lab uses the same zip structure so submissions are complete and easy to grade.

For students: Submit one zip file per lab. Use lowercase names. Replace lastname and firstname with your name.

Rules for Every Lab

  1. Zip file name: see each lab below (example: chapter1-smith-jane.zip).
  2. Include a reflections.txt file with answers labeled Q1:, Q2:, and so on.
  3. Save screenshots as PNG files inside a screenshots/ folder.
  4. Use the exact screenshot file names listed for each lab.
  5. Swift and Firebase labs also include code.swift with all Swift files combined.
  6. Tool labs (GitHub, Figma, Trello, Slack) include a links.txt file for URLs.

Standard Zip Structure

your-lab-zip-name.zip
├── code.swift          (Swift labs and Firebase only)
├── links.txt           (tool labs only — GitHub, Figma, Trello, Slack)
├── commit-messages.txt (GitHub lab only)
├── reflections.txt
├── exports/            (Figma lab only)
│   └── campus-welcome-wireframe.png
└── screenshots/
    ├── preview.png
    └── (other files named in the lab)

How to Create a Zip File on a Mac

Follow these steps before you upload to Canvas.

  1. Open Finder and go to your Desktop (or another easy-to-find location).
  2. Create a new folder: File → New Folder. Name it for your lab (example: chapter1-smith-jane).
  3. Put all required files inside that folder:
    • reflections.txt
    • code.swift (Swift and Firebase labs)
    • links.txt and other tool-lab files when required
    • a screenshots folder containing your PNG files
  4. Check the folder one last time. Every required file name should match the lab submission guide.
  5. Right-click the folder (or Control-click).
  6. Choose Compress "folder name". Finder creates a file named folder name.zip in the same location.
  7. If needed, rename the zip file to match the lab (example: chapter1-smith-jane.zip).
  8. Open Canvas, go to the assignment, and upload the zip file.

Tips

  • Compress the folder, not individual files. Your zip should open to show files and folders at the top level.
  • Do not submit a .rar or .7z file. Canvas expects a standard .zip.
  • If the zip is larger than the Canvas limit, shrink PNG screenshots or ask your instructor.
  • To check your zip, double-click it. Confirm you see reflections.txt, screenshots/, and any other required files.
